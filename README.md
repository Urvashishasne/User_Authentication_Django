# Django User Authentication Project

A **Django** project demonstrating a complete **user authentication system** with signup, login, logout, and dashboard features.

This project is ideal for showcasing backend skills, database management, and frontend integration using **Bootstrap**.

---

## 🚀 Features

- User **Signup**, **Login**, and **Logout**
- Dashboard accessible only to **authenticated users**
- Separate **Admin panel** for superusers
- Form validation and error handling
- **Role-based access** (Normal user vs Admin)
- Bootstrap-styled **responsive templates**

---

## 💻 Technologies Used

- **Python 3.x**  
- **Django 5.2.10**  
- **SQLite** (default development database)  
- **Bootstrap 5** for styling  
- **HTML/CSS** templates
